# @okkey/email-templates

React Email layouts for Core transactional mail. Strings come from `@okkey/i18n` (ICU JSON), not from inline copy in components.

## Scripts

- `yarn build` — emit `dist/` (run from repo root: `yarn build:email-templates`).
- `yarn dev` — preview server (`email dev --dir emails --port 3030`). From monorepo root: `yarn dev:email`.

Preview templates live in `emails/`; production components in `src/components/`.
