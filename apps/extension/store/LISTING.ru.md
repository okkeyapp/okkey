# Store listing — русский (`1.0.0.2`)

Для AMO (locale `ru`) и опционально CWS/Edge русской локали. Английский — источник для международных витрин: [LISTING.en.md](./LISTING.en.md).

## Краткое описание

**Лимит ~132 символа.**

```text
Менеджер паролей для своего сервера: клиентский сейф, постквантовая криптография, автозаполнение.
```

Альтернатива:

```text
Постквантовый менеджер паролей: свой сервер, шифрование на устройстве, автозаполнение логина и TOTP.
```

## Подробное описание

```text
Okkey — менеджер паролей для развёртывания на своей инфраструктуре. Упор на максимальную защиту на клиенте и криптографию с учётом постквантовых (Q-day) угроз.

Вы разворачиваете Okkey на своей инфраструктуре. Расширение подключается к адресу вашего сервера Okkey (свой сервер или localhost). Синхронизация идёт с вашим сервером, расшифровка — только на устройстве.

Зачем Okkey
• Клиентский сейф — секреты расшифровываются в расширении, а не на сервере
• Постквантовая криптография — расчёт на долгую конфиденциальность в мире после Q-day
• Свой сервер — вы выбираете, где хранятся зашифрованные данные
• Автозаполнение — логин, пароль и TOTP на сайтах, которые вы сохранили; область: весь сайт / точный URL / не заполнять
• Доверенные устройства — расширение регистрируется как новое устройство и ждёт подтверждения
• Локальная разблокировка — мастер-пароль (и опционально PIN) только в расширении после входа

Как войти
1. Укажите адрес (URL) вашего веб-приложения Okkey
2. Войдите через веб-вход вашего сервера (PKCE) — SSO/2FA остаются в веб-приложении
3. Подтвердите устройство с уже доверенного клиента
4. Разблокируйте сейф локально и пользуйтесь автозаполнением

Конфиденциальность
Доступ к сайтам нужен только чтобы находить формы входа и подставлять сохранённые вами данные. Мы не продаём историю браузинга и не исполняем удалённый код. Политика конфиденциальности — по ссылке в карточке магазина; исходники — на GitHub.

Репозиторий: https://github.com/okkeyapp/okkey

Сборка расширения: 1.0.0.2.
```
