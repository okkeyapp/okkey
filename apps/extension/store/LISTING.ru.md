## Подробное описание

```text
Okkey — self-hosted менеджер паролей с упором на максимальную защиту на клиенте и криптографию с учётом постквантовых (Q-day) угроз.

Вы разворачиваете Okkey на своей инфраструктуре. Расширение подключается к URL вашего инстанса (self-hosted или localhost). Обязательного SaaS-бэкенда нет: синхронизация идёт с вашим сервером, расшифровка — только на устройстве.

Зачем Okkey
• Клиентский сейф — plaintext секретов не появляется на сервере
• Post-quantum ready crypto — расчёт на долгую конфиденциальность в мире после Q-day
• Self-host first — вы выбираете, где хранятся зашифрованные данные
• Autofill — логин, пароль и TOTP на сайтах, которые вы сохранили; область: весь сайт / точный URL / не заполнять
• Доверенные устройства — расширение регистрируется как новое устройство и ждёт approve
• Локальный unlock — мастер-пароль (и опционально PIN) только в расширении после входа

Как войти
1. Укажите base URL вашего Okkey web
2. Войдите через web-логин инстанса (PKCE) — SSO/2FA остаются в web
3. Подтвердите устройство с уже доверенного клиента
4. Разблокируйте сейф локально и пользуйтесь autofill

Конфиденциальность
Доступ к сайтам нужен только чтобы находить формы входа и подставлять сохранённые вами данные. Мы не продаём историю браузинга и не исполняем удалённый код. Политика конфиденциальности — по ссылке в карточке магазина; исходники — на GitHub.

Репозиторий: https://github.com/okkeyapp/okkey

Сборка расширения 1.0.0.2. Функции и материалы витрины могут обновляться.
```
