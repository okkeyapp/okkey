# Okkey browser extension — Support

**Product:** Okkey (self-hosted password manager)  
**Repository:** [https://github.com/okkeyapp/okkey](https://github.com/okkeyapp/okkey)  
**Extension pack:** store listing docs under `apps/extension/store/`

## How to get help

1. **Bug reports & feature requests** — open an issue on the public repo:  
   [https://github.com/okkeyapp/okkey/issues](https://github.com/okkeyapp/okkey/issues)
2. **Security-sensitive reports** — prefer a private channel if the repo publishes one (SECURITY.md / maintainer contact); otherwise mark the issue clearly and avoid pasting secrets, vault plaintext, or production credentials.
3. **Self-host / operator questions** — contact the administrator of **your** Okkey instance (you configure the extension’s Server URL yourself).

## Beta note

Store builds may change quickly. Include the extension version (`1.0.0.2` / manifest `version`), browser name, and whether you use a self-hosted or local Okkey instance when filing an issue.
