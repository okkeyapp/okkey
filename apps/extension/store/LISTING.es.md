## Detailed description

**Edge Add-ons:** description per language must be **≥250** and ≤10 000 characters.

```text
Okkey es un gestor de contraseñas autoalojado pensado para la máxima protección en el cliente, incluida una criptografía diseñada con un modelo de amenazas poscuántico (Q-day).

Usted ejecuta Okkey en su propia infraestructura. La extensión del navegador se conecta a la URL de la instancia de Okkey que configure (autoalojada o local). Su bóveda se sincroniza con su servidor; el descifrado ocurre en su dispositivo.

Por qué Okkey
• Bóveda en el cliente — los secretos se descifran en la extensión, no en el servidor
• Criptografía lista para el poscuántico — pensada para una confidencialidad duradera ante amenazas cuánticas
• Autoalojamiento primero — aporte su propio despliegue de Okkey; usted controla dónde viven los datos cifrados
• Autocompletado bien hecho — rellene registros de cualquier tipo (inicios de sesión, contraseñas, TOTP y otros campos), con avisos de guardar/actualizar y ámbitos por URL (sitio completo / URL exacta / nunca)
• Dispositivos de confianza — la extensión se registra como dispositivo y espera la aprobación de un dispositivo que usted ya confía
• Desbloqueo local — la contraseña maestra, un PIN opcional o la biometría desbloquean la bóveda solo dentro de la extensión tras el inicio de sesión

Cómo funciona el inicio de sesión
1. Introduzca la URL base de su aplicación web Okkey
2. Inicie sesión a través del acceso web de su instancia — SSO/2FA permanecen en la aplicación web
3. Apruebe el nuevo dispositivo de la extensión desde un dispositivo de confianza
4. Desbloquee localmente y use el autocompletado en los sitios que elija

Privacidad y permisos
Okkey necesita acceso a los sitios que visita solo para detectar formularios de inicio de sesión y autocompletar las credenciales que usted guardó. No vendemos datos de navegación ni ejecutamos código remoto. Consulte la política de privacidad de esta ficha y el repositorio de código abierto.

Núcleo de código abierto: https://github.com/okkeyapp/okkey

Extension build: 1.0.0.1000.
```
