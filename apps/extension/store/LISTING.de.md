## Detailed description

**Edge Add-ons:** description per language must be **≥250** and ≤10 000 characters.

```text
Okkey ist ein self-gehosteter Passwortmanager mit maximalem clientseitigem Schutz — einschließlich Kryptografie, die auf ein Post-Quanten- (Q-Day-) Bedrohungsmodell ausgelegt ist.

Sie betreiben Okkey auf Ihrer eigenen Infrastruktur. Die Browsererweiterung verbindet sich mit der von Ihnen konfigurierten Okkey-Instanz-URL (self-hosted oder lokal). Ihr Tresor synchronisiert mit Ihrem Server; die Entschlüsselung erfolgt auf Ihrem Gerät.

Warum Okkey
• Clientseitiger Tresor — Geheimnisse werden in der Erweiterung entschlüsselt, nicht auf dem Server
• Post-Quanten-bereite Krypto — für langfristige Vertraulichkeit angesichts aufkommender Quantenbedrohungen
• Self-host zuerst — bringen Sie Ihr eigenes Okkey-Deployment mit; Sie kontrollieren, wo verschlüsselte Daten liegen
• Autofill richtig gemacht — gespeicherte Einträge aller Typen ausfüllen (Logins, Passwörter, TOTP und andere Felder), mit Speicher-/Update-Hinweisen und URL-Bereichen (gesamte Site / exakte URL / nie)
• Vertrauenswürdige Geräte — die Erweiterung registriert sich als Gerät und wartet auf Freigabe von einem bereits vertrauenswürdigen Gerät
• Lokale Entsperrung — Master-Passwort, optionaler PIN oder Biometrie entsperren den Tresor nur innerhalb der Erweiterung nach der Anmeldung

So funktioniert die Anmeldung
1. Geben Sie die Basis-URL Ihrer Okkey-Web-App ein
2. Melden Sie sich über den Web-Login Ihrer Instanz an — SSO/2FA bleiben in der Web-App
3. Genehmigen Sie das neue Erweiterungsgerät von einem vertrauenswürdigen Gerät aus
4. Entsperren Sie lokal und nutzen Sie Autofill auf den Sites Ihrer Wahl

Datenschutz & Berechtigungen
Okkey benötigt Zugriff auf von Ihnen besuchte Websites nur, um Anmeldeformulare zu erkennen und von Ihnen gespeicherte Anmeldedaten auszufüllen. Wir verkaufen keine Surfdaten und führen keinen Remote-Code aus. Siehe die Datenschutzerklärung in diesem Listing und das Open-Source-Repository.

Open-Source-Kern: https://github.com/okkeyapp/okkey

Extension build: 1.0.0.1000.
```
