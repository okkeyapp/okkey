# Store visual assets checklist

Icons shipped in the extension package (`public/icon-*.png`) are enough for the **toolbar**. Stores also require **listing screenshots** (and often a promo tile). Keep final PNGs here when ready; this folder may start empty except this README.

## Required (typical)

| Asset | CWS | Edge | Opera | AMO |
|-------|-----|------|-------|-----|
| Screenshot(s) 1280×800 or 640×400 | ✓ | ✓ | ✓ | ✓ (min 1) |
| Small promo tile 440×280 | often | — | — | — |
| Marquee 1400×560 | optional | — | — | — |
| Extension icon 128×128 | from package | from package | from package | from package |

## Suggested shots for Okkey beta

1. Popup unlocked — vault list + item card  
2. Autofill overlay on a login form  
3. Server URL / self-host setup screen  
4. Unlock screen (master password)  
5. Device pending approval (optional)

Capture from a **self-hosted** demo instance (no SaaS-only branding). Avoid real customer secrets; use disposable demo credentials.

screenshot-01-vault-popup-en.png
