## Detailed description

**Edge Add-ons:** description per language must be **≥250** and ≤10 000 characters.

```text
Okkey est un gestionnaire de mots de passe auto-hébergé conçu pour une protection maximale côté client — y compris une cryptographie pensée pour un modèle de menace post-quantique (Q-day).

Vous exécutez Okkey sur votre propre infrastructure. L'extension de navigateur se connecte à l'URL d'instance Okkey que vous configurez (auto-hébergée ou locale). Votre coffre se synchronise avec votre serveur ; le déchiffrement a lieu sur votre appareil.

Pourquoi Okkey
• Coffre côté client — les secrets sont déchiffrés dans l'extension, pas sur le serveur
• Crypto prête pour le post-quantique — conçue pour une confidentialité durable face aux menaces quantiques
• Auto-hébergement d'abord — apportez votre propre déploiement Okkey ; vous contrôlez où vivent les données chiffrées
• Remplissage automatique bien fait — remplissez des enregistrements de tout type (identifiants, mots de passe, TOTP et autres champs), avec invites d'enregistrement/mise à jour et portées d'URL (site entier / URL exacte / jamais)
• Appareils de confiance — l'extension s'enregistre comme appareil et attend l'approbation d'un appareil déjà de confiance
• Déverrouillage local — le mot de passe principal, un PIN optionnel ou la biométrie déverrouillent le coffre uniquement dans l'extension après la connexion

Comment fonctionne la connexion
1. Saisissez l'URL de base de votre application web Okkey
2. Connectez-vous via la connexion web de votre instance — SSO/2FA restent dans l'application web
3. Approuvez le nouvel appareil d'extension depuis un appareil de confiance
4. Déverrouillez localement et utilisez le remplissage automatique sur les sites de votre choix

Confidentialité et autorisations
Okkey a besoin d'accéder aux sites que vous visitez uniquement pour détecter les formulaires de connexion et remplir les identifiants que vous avez enregistrés. Nous ne vendons pas les données de navigation et n'exécutons pas de code distant. Voir la politique de confidentialité liée à cette fiche et le dépôt open source.

Noyau open source : https://github.com/okkeyapp/okkey

Extension build: 1.0.0.1000.
```
