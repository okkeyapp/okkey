## Detailed description

```text
Okkey é um gerenciador de senhas self-hosted feito para proteção máxima no cliente — incluindo criptografia projetada com um modelo de ameaça pós-quântica (Q-day).

Você executa o Okkey na sua própria infraestrutura. A extensão do navegador conecta-se ao URL da instância Okkey que você configura (self-hosted ou local). Seu cofre sincroniza com o seu servidor; a descriptografia acontece no seu dispositivo.

Por que Okkey
• Cofre no cliente — os segredos são descriptografados na extensão, não no servidor
• Criptografia pronta para o pós-quântico — pensada para confidencialidade de longo prazo diante de ameaças quânticas
• Self-host em primeiro lugar — use o seu próprio deployment Okkey; você controla onde os dados criptografados ficam
• Preenchimento automático bem feito — preencha registros de qualquer tipo (logins, senhas, TOTP e outros campos), com avisos de salvar/atualizar e escopos por URL (site inteiro / URL exata / nunca)
• Dispositivos confiáveis — a extensão registra-se como dispositivo e aguarda aprovação de um dispositivo em que você já confia
• Desbloqueio local — a senha mestra, um PIN opcional ou a biometria desbloqueiam o cofre apenas dentro da extensão após o login

Como funciona o login
1. Informe o URL base do seu app web Okkey
2. Entre pelo login web da sua instância — SSO/2FA permanecem no app web
3. Aprove o novo dispositivo da extensão a partir de um dispositivo confiável
4. Desbloqueie localmente e use o preenchimento automático nos sites que escolher

Privacidade e permissões
O Okkey precisa acessar os sites que você visita apenas para detectar formulários de login e preencher as credenciais que você salvou. Não vendemos dados de navegação e não executamos código remoto. Veja a política de privacidade desta listagem e o repositório open source.

Núcleo open source: https://github.com/okkeyapp/okkey

Extension build: 1.0.0.1000.
```
