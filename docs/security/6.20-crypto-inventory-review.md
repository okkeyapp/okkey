## Hidden or Sensitive Nodes

1. `scripts/ensure-crypto-wasm-dist.mjs` bootstrap package can mask provenance drift if real WASM build step is skipped.
2. `security-suite.yml` defaults to `dev` crypto policy (`1,2`) which is valid for tests but can under-detect prod-only policy violations.
3. `totp-rfc6238.ts` uses `HMAC-SHA1` (RFC-compliant for TOTP), so this must stay explicitly scoped as auth OTP crypto, not vault-data crypto.
4. Edge/ingress TLS enforcement cannot be fully attested from this repository alone; needs cross-check with deployment artifacts.
