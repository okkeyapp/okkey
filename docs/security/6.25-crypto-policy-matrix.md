# 6.25 Crypto Policy Matrix (`dev/stage/prod`)

This document is the human-readable view of the canonical crypto policy matrix.

Canonical machine-readable source:
- `services/api/src/crypto/policy-matrix.ts`

## Scope

- Environments: `dev`, `stage`, `prod`
- Profiles: `v1`, `v2`
- Controls: lifecycle/deprecation windows, rollout defaults, feature-gate bindings

## Canonical Schema

The canonical matrix uses:

- `schemaVersion`
- `lifecyclePolicy` (owner + review cadence)
- `environments[env]`:
  - `defaultRolloutMode`
  - `featureGates`
  - `profiles[]` with:
    - `version`, `configId`, `state`, `allowedForWrite`
    - `encryptedBlobAlgorithm`
    - `deprecation` window (`announcedOn`, `startsOn`, `graceEndsOn`, `removalTarget`)

## Policy Matrix

| Env | Profile | State | Allowed for write | Rollout default | Notes |
| --- | --- | --- | --- | --- | --- |
| `dev` | `v1` | `deprecated` | `yes` | `compat` | Legacy profile for local development and fixtures only. |
| `dev` | `v2` | `active` | `yes` | `compat` | Q-Day default profile. |
| `stage` | `v1` | `forbidden` | `no` | `compat` | Legacy profile is blocked for stage write paths. |
| `stage` | `v2` | `active` | `yes` | `compat` | Q-Day default profile. |
| `prod` | `v1` | `forbidden` | `no` | `strict` | Legacy profile is blocked for production write paths. |
| `prod` | `v2` | `active` | `yes` | `strict` | Q-Day default profile. |

## Lifecycle and Deprecation

`v1` lifecycle window:
- `announcedOn`: `2026-03-29`
- `startsOn`: `2026-03-29`
- `graceEndsOn`: `2026-09-30`
- `removalTarget`: `2026-12-31`

## Feature Gates Binding

The matrix is explicitly bound to rollout controls:
- `CRYPTO_ROLLOUT_MODE`
- `CRYPTO_ROLLOUT_ENABLED`
- `CRYPTO_ROLLOUT_STATE`
- `CRYPTO_ROLLOUT_STOP_WRITE_PATHS`

## CI and Validation

- Unit validation enforces matrix schema consistency.
- Policy consistency tests enforce alignment with runtime defaults and crypto registry.
- CI gate fails build on policy drift.
