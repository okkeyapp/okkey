# 6.12 Threat-to-Test Matrix (Q-Day security suite)

This matrix maps Q-Day threats to automated tests and expected invariants.
It consolidates coverage from tasks `6.4`, `6.10`, and `6.11`, and defines explicit
coverage required by task `6.12`.

## Coverage matrix

| Threat | Layer | Existing tests | New 6.12 suite tests | Expected invariant / error |
| --- | --- | --- | --- | --- |
| Downgrade attack (`crypto_version` below vault/event floor) | API backend (`sync`, `vault-sharing`) | `services/api/test/crypto.downgrade.test.ts`, `services/api/test/crypto-vault-floor.test.ts`, `services/api/test/vault-sharing.integration.test.ts` | `services/api/test/security-qday-downgrade-strip.test.ts` | Reject with `CRYPTO_DOWNGRADE_NOT_ALLOWED`; no lower profile event append |
| Strip attack (remove `crypto_version` / legacy ciphertext shape) | API request validation (`sync`) | `services/api/test/sync.service.test.ts` | `services/api/test/security-qday-downgrade-strip.test.ts` | Reject with `SYNC_BAD_REQUEST`; no event write |
| Missing PQ key for recipient in production | Vault sharing / rotation policy | `services/api/test/vault-sharing.integration.test.ts` | `services/api/test/security-qday-missing-pq-malformed-envelope.test.ts` | Reject with `VAULT_SHARE_RECIPIENT_PQ_REQUIRED` |
| Malformed hybrid envelope on API boundary | EncryptedBlob parse + wrap metadata checks | Partial: malformed non-base64 and wrong metadata checks in `vault-sharing.integration.test.ts` | `services/api/test/security-qday-missing-pq-malformed-envelope.test.ts` | Reject with `VAULT_KEY_WRAP_INVALID` for malformed metadata/envelope shape even with valid base64 payload |
| Mixed-device sessions (stale device after rotation) | Client sync/outbox + replay | Partial: `services/api/test/sync-outbox.test.ts`, `services/api/test/sync-replay-engine.test.ts` | `services/api/test/security-qday-mixed-device-replay-rollback.test.ts` | Stale session must not replay old base version; conflict handled via `VERSION_MISMATCH` + rebase/refetch |
| Replay edge case (duplicate and stale rotation events) | Replay engine | `services/api/test/sync-replay-engine.test.ts` | `services/api/test/security-qday-mixed-device-replay-rollback.test.ts` | Deterministic convergence, duplicate ignored by id, stale versions quarantined with `STALE_VERSION_NOT_DUPLICATE` |
| Rollback edge case (version gap from partial/rolled-back history) | Replay engine | Partial: `SyncReplayEngine rejects version gap` in `sync-replay-engine.test.ts` | `services/api/test/security-qday-mixed-device-replay-rollback.test.ts` | Fail fast with `EventGapError` (`EVENT_GAP` semantic) |

## CI gate requirement

Task `6.12` requires this suite to be blocking for merge:

- mandatory script: `yarn test:security`
- mandatory CI job: `security-suite` (PR + push)
